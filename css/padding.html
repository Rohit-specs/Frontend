Padding

All side padding in one line

Syntax

.padding_1 { padding: 10px; }
.padding_2 { padding: 10px, 12px; }
.padding_3 { padding: 10px, 12px, 10px; }
.padding_3 { padding: 10px, 12px, 12px, 10px; }
  • One value : Same padding on all sides
  • Two value : first value is padding of top-bottom and second value is for left-right
  • Three value : first value is padding of top
    second value is for left-right
    Third value decide the padding of bottom
  • Four value : first value is padding of top
    second value is for right
    Third value decide the padding of bottom
    Forth value decide the padding of left side
